## Default Permission

Every Fluxy mobile bridge command.

#### This default permission set includes the following:

- `allow-secret-get`
- `allow-secret-set`
- `allow-keystore-available`
- `allow-fs-pick-source`
- `allow-fs-open-source`
- `allow-fs-export`
- `allow-storage-available`
- `allow-receive-dir-status`
- `allow-fs-pick-receive-dir`
- `allow-shared-files`
- `allow-foreground-start`
- `allow-foreground-stop`
- `allow-system-insets`
- `allow-set-chrome-color`
- `allow-local-network-info`
- `allow-discovery-start`
- `allow-discovery-stop`
- `allow-discovery-peers`
- `allow-open-chat`
- `allow-notify-chat`
- `allow-open-file`
